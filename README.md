# Viettel_logistics
HUBDNG cung cấp và điều phối các giải pháp logistics, kho bãi, lưu trữ, trung chuyển, vận tải và phân phối hàng hóa. Trung tâm phù hợp với doanh nghiệp cần thuê kho, trung chuyển hàng hóa, vận chuyển liên tỉnh hoặc xây dựng giải pháp logistics tại khu vực Đà Nẵng và miền Trung.
